# Agentic Fraud Modelling Pipeline

Interactive technical blog built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — article content and interactive components
- `style.css` — minimalist editorial styling
- `script.js` — pipeline, feature, metric and TPE interactions

## Deploy

Upload the three files to the root of a GitHub repository and enable:

Settings → Pages → Deploy from a branch → `main` → `/ (root)`

## Before publishing

Replace the illustrative metric values and result placeholders with actual experimental results.
